# 05 运行时工程

> 归属：AI Coding Agent 软件工程手册

## API

- **错误响应结构化**：稳定的错误码 + 面向用户的消息 + 可选详情。禁止裸字符串。
- **可重试的写操作必须幂等**：支付、创建订单、回调重放、消息消费。用幂等键或去重表。查询和天然幂等的更新不需要额外机制。
- **禁止泄漏内部实现**：不返回数据库列名、内部 ID 规则、堆栈信息。
- **分页、限流、超时是默认项**，不是可选项。

## 数据

- **数据库结构不等于领域模型**。领域建模适合规则复杂、状态迁移多的场景；内部 CRUD 工具直接映射表结构是合理选择，不要为了"DDD"造无谓的映射层。
- **数据访问集中在 repository**，业务层不写 SQL。
- **禁止 N+1 查询**：检查 ORM 懒加载、循环内查询、重复请求。
- **迁移可回滚**，且与代码发布解耦（代码先兼容两种结构，再迁移数据，最后清理）。

## 事务与并发

- **事务边界明确**：在 application 层开启，不在 domain 内部散落。
- **禁止长事务**：事务内不做网络调用、不发消息、不等待用户。
- **耗时任务异步化**：邮件、报表、AI 推理、视频处理进队列。
- **禁止阻塞主线程**：识别 CPU 密集、阻塞 IO、长事务，交给线程池或异步运行时。
- **所有外部调用有超时**：HTTP、RPC、MQ、数据库。没有超时等于把局部故障放大成全站不可用。
- **重试必须有退避和抖动**，且只重试幂等操作。
- **必须有背压**：无界队列只是把内存耗尽推迟到更晚。

## 缓存

- **必须可失效**：TTL、主动失效、版本号，至少一种。
- **防击穿**：单飞（singleflight）、随机 TTL、多级缓存。
- **缓存不参与正确性**。缓存挂了，系统要能降级到源数据。

## 日志与可观测

- **结构化日志**，包含 trace_id、user_id、事件名。禁止 `print` 调试残留。
- **禁止记录敏感信息**：密码、token、密钥、身份证、银行卡。
- **三大件齐备**：指标（延迟、错误率、QPS、饱和度）、链路追踪、日志。
- **告警要可行动**。每条告警对应一个明确处置动作，没有动作的告警是噪音。

## 安全

- **所有外部输入在边界校验一次**：类型、长度、格式、白名单。转换成内部类型后不再重复校验。
- **最小权限**：服务账号、数据库账号、密钥权限按需授予。
- **密钥不入库**：环境变量或密钥管理服务。日志、异常、监控上报都要脱敏。
- **依赖审计进 CI**：已知漏洞、许可证、传递依赖。
- **输出转义**：渲染 HTML、拼 shell、拼 SQL、写终端都要转义。不可信输入永远不作为代码或命令执行。
